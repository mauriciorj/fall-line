# Project Rules

- For changes under `crawler/mountains/**`, use `.devin/skills/create-mountain-crawler/SKILL.md`.
- Preserve the five-table crawler contract: `resorts`, `resortHours`, `resortRates`, `resortRentals`, and `weatherAndStatus`.
- Keep `resortId`, `sourceUrl`, and `updatedAt` in every generated table payload.
- Do not invent unavailable mountain data. Use explicit empty or closed/not-informed fallbacks.
- Compile generators and run the resort snapshot generator before completion. Review `snapshot_generator_report.json`.
- Do not run `main.py` unless Convex publishing side effects are intended.
- New resort onboarding: `python crawler/super-crawler/super_crawler.py <url>` crawls the whole site (no Convex calls) and writes `crawler/super-crawler/output/<resortId>/discovery.json` + `static_infos.draft.json` (gitignored). Then build generators with the `create-mountain-crawler` skill from the `pageMap`. See `crawler/super-crawler/README.md`.
- i18n: locale is a URL segment (`src/app/[locale]`); EN is unprefixed, `/fr` and `/es` prefixed. `src/proxy.ts` rewrites unprefixed paths to `/en/...` and 308s `/en/...` to unprefixed. Use `Link` from `src/i18n/link.tsx` for internal links in client components and `localizePath()` in server components. Translations live in `src/i18n/translations.ts` (`getTranslator(locale)` works server-side). EN-only content (blog, privacy, terms) uses `englishOnlyAlternates`; translated pages use `localizedAlternates` (self canonical + hreflang).
- After adding/removing routes, stale `.next/dev/types` can fail `next build` typechecking; run `next dev` once (or remove `.next/dev`) to regenerate.
- Resort images: `scripts/generateResortAssets.mjs` scans `public/assets/resorts` and writes `src/data/resortAssets.json` (which hero/og/trail-map files exist). `pnpm dev`/`pnpm build` run it; rerun after adding assets. Resorts without a hero fall back to `/opengraph-image`.
- Brand icons (`src/app/favicon.ico`, `icon0.svg`, `icon1.png`, `apple-icon.png`, `public/icons/*`) are generated by `node scripts/generateBrandIcons.mjs` from the lucide mountain glyph + `#4A6FA5`; edit the script, not the files. `src/app/manifest.ts` and the JSON-LD Organization logo reference `public/icons`.
- After adding/replacing resort images run `node scripts/optimizeResortImages.mjs` (sharp): keeps `hero.webp` ≤ 400 KB (1920w, q75), trail maps ≤ ~400 KB where possible (2400w, q85), and generates `og.jpg` (1200x630 social crop). Only touches files that are missing or over budget; commit the results.
- Convex CLI behind the corporate TLS proxy needs `NODE_USE_SYSTEM_CA=1` (e.g. `NODE_USE_SYSTEM_CA=1 pnpm exec convex dev --once`).
- `NEXT_PUBLIC_SUPPORT_EMAIL`: contact address shown on contact/privacy/terms and in Organization JSON-LD. Unset → no email is rendered (never use a placeholder address).
- SEO env: set `NEXT_PUBLIC_SITE_URL` (production origin, used for `metadataBase`/canonical/OG URLs; falls back to `VERCEL_PROJECT_PRODUCTION_URL`, then `http://localhost:3000`) and optionally `GOOGLE_SITE_VERIFICATION` (Search Console token).
- `next build` calls the Convex deployment (`NEXT_PUBLIC_CONVEX_URL`) for `generateStaticParams` and the footer; the root layout and data pages use `dynamic = "force-static"` + `revalidate` because `convex/nextjs` forces `cache: "no-store"`. Server-side `cookies()`/`headers()` are therefore empty — do not rely on them.
